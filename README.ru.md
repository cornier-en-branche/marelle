**Настраиваемый ИИ-агент для вашего терминала.**
Подключаете свои API-ключи: Z.ai (Zhipu GLM), Anthropic, OpenAI, OpenRouter, локальный Ollama или любой OpenAI-совместимый сервер. Сначала Linux и Termux.

[English](README.md) | Русский

> **Pre-alpha, версия 0.1.0-alpha.1.** Реализованы нативный TUI, чат с несколькими провайдерами, агентский цикл с подтверждением действий, локальные инструменты и сохранение сессий. API и настройки ещё могут меняться. Это прототип, а не полная копия OpenCode или Hermes.

*Marelle* по-французски значит «классики» (игра в «прыгалки»). Каждый квадрат это шаг.

## Установка

**Termux на Android.** Скачайте готовый бинарник на странице [Releases](https://github.com/cornier-en-branche/marelle/releases) или соберите на телефоне. Пошаговая инструкция: [docs/TERMUX.ru.md](docs/TERMUX.ru.md).

**Linux и всё остальное, где есть Rust.** Нужен Rust 1.85 или новее:

```sh
cargo install --locked --git https://github.com/cornier-en-branche/marelle marelle-cli
```

Или склонируйте репозиторий и выполните `cargo build --release`. Бинарник лежит в `target/release/marelle`, около 4 МиБ.

## Первый разговор

Храните ключ в файле, который читаете только вы, и скажите Marelle, где он лежит. В настройках Marelle ключ не хранится никогда.

```sh
mkdir -p ~/.config/marelle
( umask 077; read -rsp "API-ключ: " key; echo; printf '%s' "$key" > ~/.config/marelle/zai.key )
export MARELLE_PROVIDERS__ZAI__API_KEY_FILE=~/.config/marelle/zai.key

marelle providers                                    # что есть и найден ли ключ
marelle config set chat.provider zai
marelle config set chat.model glm-5.2
marelle                                                # открыть интерактивный интерфейс
marelle chat -m zai/MODEL "Объясни игру в классики одним предложением"
```

Вместо `MODEL` подставьте название модели из списка вашего провайдера. Другие способы:

```sh
marelle                                                # интерактивный TUI, если chat.model настроена
marelle --tui                                           # явно открыть TUI
marelle --continue                                      # продолжить последнюю сохранённую беседу
marelle chat -q "Объясни устройство этого проекта"      # один запрос и выход
marelle chat -m zai/MODEL                               # интерактивный TUI с временной моделью
git diff | marelle chat -m zai/MODEL "Проверь:" -      # "-" означает данные из конвейера
marelle chat -p anthropic -m MODEL --show-usage "Почему небо голубое?"
```

Ответ уходит в stdout. Рассуждения, число токенов, заметки и ошибки уходят в stderr, поэтому `marelle chat ... > answer.txt` сохранит только ответ.

## Инструменты агента

Marelle передаёт моделям структурированные описания инструментов через OpenAI-compatible и Anthropic API. Встроенные инструменты:

| Инструмент | Назначение |
| --- | --- |
| `terminal` | Выполнить команду в оболочке из каталога запуска |
| `read_file`, `write_file`, `edit_file` | Читать и изменять текстовые файлы UTF-8 |
| `list_directory`, `search_text` | Просматривать и искать файлы проекта |
| `fetch_url` | Получить публичную HTTP(S)-страницу как текст (нужен `curl`) |
| `list_skills`, `load_skill` | Найти и загрузить локальные инструкции `SKILL.md` |

Команда `/tools` показывает инструменты, `/skills` — доступные навыки. Контекст проекта автоматически берётся из `AGENTS.md`, `CLAUDE.md`, `SOUL.md`, `.cursorrules` и некоторых файлов `.marelle/`, только если они находятся внутри разрешённых путей.

Файловые инструменты ограничены `permissions.allowed_paths` (по умолчанию — текущий каталог проекта) и учитывают `permissions.denied_paths`. Чтение разрешено по умолчанию; изменение файлов, команды оболочки и загрузка URL требуют подтверждения. Разрешение shell относится ко всей системе и не является файловой песочницей: оставляйте его в режиме `ask`, если сознательно не доверяете модели выполнение команд.

Агент останавливается после `agent.max_turns` раундов вызова инструментов. Содержимое ответов инструментов рассматривается как недоверенные данные. Запросы используют полный ответ модели, чтобы не собирать аргументы инструментов из неполных потоковых фрагментов.

## Сессии

Беседы по умолчанию сохраняются локально вместе с историей вызовов инструментов и настройками модели/сессии. В Unix каталог сессий имеет права `0700`, JSON-файл — `0600`. Путь: `$XDG_STATE_HOME/marelle/sessions.json` или `~/.local/state/marelle/sessions.json`, если `XDG_STATE_HOME` не задан. API-ключи в файл не записываются. Отключить сохранение:

```sh
marelle config set agent.persist_sessions false
```

Коды выхода: `0` успех, `1` ошибка провайдера или сети, `2` ошибка в вызове или в настройках.

## Провайдеры

| id | Протокол | Переменная ключа | |
| --- | --- | --- | --- |
| `zai` | OpenAI-совместимый | `ZAI_API_KEY` | Z.ai (Zhipu GLM), международный |
| `zai_coding` | OpenAI-совместимый | `ZAI_API_KEY` | Z.ai GLM Coding Plan |
| `zai_anthropic` | Anthropic | `ZAI_API_KEY` | Z.ai, адрес в стиле Anthropic |
| `zhipu` | OpenAI-совместимый | `ZHIPUAI_API_KEY` | Zhipu BigModel, Китай |
| `zhipu_coding` | OpenAI-совместимый | `ZHIPUAI_API_KEY` | Zhipu BigModel Coding Plan, Китай |
| `anthropic` | Anthropic | `ANTHROPIC_API_KEY` | Claude |
| `openai` | OpenAI-совместимый | `OPENAI_API_KEY` | OpenAI |
| `openrouter` | OpenAI-совместимый | `OPENROUTER_API_KEY` | много моделей за одним ключом |
| `ollama` | OpenAI-совместимый | нет | Ollama на этом компьютере |

Адреса Z.ai и Zhipu взяты из сторонней документации, а не со страниц самого вендора. Сверьте их со своим тарифом и переопределите поле, если они отличаются.

Любое поле провайдера можно изменить, а новый провайдер это просто имя с адресом:

```sh
export MARELLE_PROVIDERS__GATEWAY__BASE_URL=https://llm.example.com/v1
export MARELLE_PROVIDERS__GATEWAY__API_KEY_ENV=GATEWAY_KEY
marelle chat -p gateway -m some-model "привет"
```

Остальные поля провайдера: `kind` (`openai-compatible` или `anthropic`), `api_key_file`, `auth` (`bearer`, `x-api-key`, `api-key`, `none`), `max_tokens_field`, `stream_usage` и `extra_body`. Если переменная из `api_key_env` задана, берётся она, иначе читается файл.

## Настройки

Настройки идут слоями: встроенные значения, затем переменные окружения, затем флаги. Следующим шагом между значениями по умолчанию и окружением встанут файлы настроек.

- `MARELLE_CHAT__MODEL=zai/MODEL` задаёт `chat.model`. Двойное подчёркивание заменяет точку.
- `marelle config show [префикс]` перечисляет настройки и слой, откуда пришла каждая.
- `marelle config explain <ключ>` показывает все слои, где задан ключ, от низшего приоритета к высшему.

| Ключ | По умолчанию | Смысл |
| --- | --- | --- |
| `chat.provider`, `chat.model` | нет | С кем говорить. `chat.model` может быть `провайдер/модель`. |
| `chat.system` | нет | Системный промпт |
| `chat.max_tokens`, `chat.temperature` | нет | Если не заданы, решает провайдер |
| `chat.stream` | `true` | Печатать ответ по мере поступления |
| `chat.show_reasoning`, `chat.show_usage` | `false` | Рассуждения и число токенов в stderr |
| `agent.max_turns` | `20` | Максимум раундов вызова инструментов на запрос |
| `agent.persist_sessions` | `true` | Сохранять локальные беседы между запусками |
| `permissions.shell` | `ask` | Запуск команд: `allow`, `ask`, `deny` |
| `permissions.files_read` | `allow` | Чтение файлов: `allow`, `ask`, `deny` |
| `permissions.files_write` | `ask` | Изменение файлов: `allow`, `ask`, `deny` |
| `permissions.network` | `ask` | Загрузка URL: `allow`, `ask`, `deny` |
| `permissions.allowed_paths` | `["."]` | Разрешённые корни файловых инструментов |
| `permissions.denied_paths` | нет | Явно запрещённые пути |
| `network.connect_timeout_secs` | `15` | Сколько ждать соединения |
| `network.idle_timeout_secs` | `300` | Сколько можно молчать при ожидании данных |
| `network.proxy` | `system` | `system`, `none` или адрес прокси |
| `network.ca_bundle` | нет | Дополнительный файл доверенных удостоверяющих центров |
| `network.allow_insecure_http` | `false` | Разрешить ключ по обычному `http` на чужой хост |

У Marelle свой список доверенных удостоверяющих центров, поэтому он работает и там, где в системе их нет, например в Termux. `SSL_CERT_FILE` добавляет ещё.

## Ключи остаются вашими

- Настройки называют переменную или файл с ключом, но не сам ключ. Настройка вроде `providers.x.api_key` отклоняется.
- Ключ не выводится в `config show`, `config explain` и `providers` и вырезается из любого текста ошибки, пришедшего от сервера.
- Он уходит только на адрес провайдера, в одном заголовке, и не уходит по обычному `http` на другой компьютер, пока вы этого не разрешите.
- Перенаправления не выполняются, поэтому ключ нельзя переслать в другое место.

## Языки

Интерфейс говорит по-английски, по-русски, по-французски и по-украински. Язык выбирается через `--lang <код>` или `MARELLE_LANG`, иначе решают `LC_ALL`, `LC_MESSAGES` и `LANG`. Все сообщения лежат в каталогах, а тест падает, если в каком-то языке чего-то не хватает. Цель: все языки Евразии, а потом и остальные.

## План

1. **Говорить.** Потоковый чат с провайдерами OpenAI-совместимого и Anthropic типов. *Готово.*
2. **Настройки и внешний вид.** Файлы настроек TOML, глобальные и для проекта, команды `config set`, `get`, `unset` и описание каждого ключа. Тематический интерфейс в духе [Hermes Agent](https://github.com/NousResearch/hermes-agent): баннер, строка состояния, ответы в рамке, спиннер. По умолчанию цвет вистерия, любой цвет задаётся через HEX.
3. **Много моделей.** Псевдонимы моделей, запрос сразу нескольким моделям со сравнением ответов, цепочки запасных моделей.
4. **Действовать.** Структурированный вызов инструментов в OpenAI-compatible и Anthropic, локальные файловые инструменты и поиск, терминал, загрузка URL, локальные навыки и права allow/ask/deny. *Прототип реализован.*
5. **Помнить.** Именованные беседы сохраняются локально между запусками. Семантическая долговременная память ещё впереди.
6. **Расширять.** MCP-серверы, внешние плагины, подагенты и более развитая поддержка навыков.
7. **Дотягиваться.** Автоматизация браузера, шлюзы мессенджеров и задачи по расписанию.

Обоснование решений описано в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Известные ограничения

- Это локальный терминальный прототип, а не полная функциональная копия OpenCode/Hermes. MCP, автоматизация браузера, подагенты, шлюзы мессенджеров и задачи по расписанию пока не реализованы.
- Селекторы провайдеров и моделей показывают настроенные провайдеры и псевдонимы моделей. Удалённые каталоги моделей пока не запрашиваются.
- Мышь работает только в селекторах; переписка и редактор ввода пока управляются клавиатурой.
- Ctrl-C завершает интерактивный сеанс, а не только текущий ответ.
- При включённых инструментах Marelle ждёт полный ответ модели, чтобы безопасно разобрать аргументы; потоковой печати токен за токеном нет.
- Команды оболочки имеют доступ к системе хоста. По умолчанию для них включён режим `ask`; `allowed_paths` ограничивает файловые инструменты, но не shell-команды.
