# Marelle

Настраиваемый ИИ-агент для вашего терминала. Подключаете свои API-ключи и настраиваете всё: какая модель отвечает за какую задачу, запасные модели, бюджеты, права и язык интерфейса.

> **Статус: pre-alpha.** В репозитории пока только каркас проекта. Цикла агента и сетевого доступа ещё нет. План описан в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

[English version](README.md)

## Что работает сейчас

- `marelle help`, `marelle version`, `marelle providers`
- `marelle config explain <ключ>` показывает, откуда взята настройка и что она переопределила. Пока команда знает встроенные значения по умолчанию и переменные окружения `MARELLE_*` (`MARELLE_AGENT__MAX_TURNS` задаёт `agent.max_turns`). Значения ключей, похожих на секретные, выводятся как `***`.
- Языки интерфейса: английский, русский и французский. Выбираются через `--lang <код>` или `MARELLE_LANG`, иначе решают обычные переменные `LC_ALL`, `LC_MESSAGES` и `LANG`.

## Сборка

Нужен Rust 1.85 или новее (разрабатывается на 1.97). Других зависимостей нет.

```sh
cargo build --release
./target/release/marelle help
cargo test --workspace
```

В Termux на Android сборка должна работать после `pkg install rust`, но это ещё не проверено.

## Цели проекта

- **Настраивается до мелочей.** Многоуровневые настройки (значения по умолчанию, глобальный файл, файл проекта, окружение, флаги), где каждое значение помнит, откуда оно пришло.
- **Много языков интерфейса.** Все сообщения лежат в каталогах, а тест падает, если в каком-то языке не хватает сообщения.
- **Ключи остаются вашими.** В настройках API-ключи задаются именем переменной окружения и никогда не хранятся.
- **Расширяется на любом языке.** Плагины будут общаться с ядром по протоколу, поэтому писать их можно на чём угодно.
- **Маленький и переносимый.** Один бинарник без рантайма. Сначала Linux и Termux.
